PyDoc v1.0.0 Stable

          
A Flow-Launcher-style quick launcher with a Windows 11 look, Python logic,
          system-tray background mode, global hotkeys, drag-and-drop, inline calculator & web search,
          usage ranking, groups, pins, aliases, per-item hotkeys, folder-content expansion and a
          Google-Material icon system.

          
    
            
  • One folder only: shortcuts come from Shortcuts/ + shortcuts.json.

  • Shortcut a folder → its files show up in search too.
    • 
            
  • Ctrl+D on a selected shortcut removes it.
